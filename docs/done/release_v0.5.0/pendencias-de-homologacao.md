# Registro de transferência de homologação — v0.5.0

A release [v0.5.0](README.md) permanece arquivada por escopo funcional. As pendências manuais antes listadas neste arquivo — Linux gráfico, leitor de tela, diálogos e clipboard nativos, responsividade sob carga, autenticação/topologias, `mongosh` em Linux e edição em servidor real — foram transferidas para a [Fase 9 / v0.13.0](../../phases/phase-09-v0.13.0/README.md).

As evidências históricas continuam na [auditoria do MVP](25-auditoria-mvp-performance.md) e na [matriz de validação](../../15-matriz-de-validacao.md). Nenhuma pendência foi encerrada pela transferência; o acompanhamento operacional passa a ocorrer exclusivamente no [checklist da Fase 9](../../16-checklist-homologacao.md).
